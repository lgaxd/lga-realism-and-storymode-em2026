# Story Mode: curated Start Dates, real calendar, simulated participants, Main Circuit only

Story Mode offers a curated set of Start Dates (January 1 of each year plus key dates) instead of any day, because any-day starts would need every player's transfer history with daily accuracy. After the Start Date, history is not replayed. Real tournaments still happen on their real dates with their real formats until 2026, but who plays in them comes from the save's own rankings: the Strength Ranking until VRS is switched on at its real introduction date. Only the Main Circuit (1.6 → CS:GO → CS2) is modelled; the parallel CS:Source scene is out of scope. Data comes from Liquipedia (CC-BY-SA, with attribution), and missing values such as pre-2010 player ratings are estimated.

## Consequences

- Maps the game has no 3D assets for are simulated and shown as text/2D only; you cannot watch them in 3D.
- Adding a Start Date means adding a data snapshot, with no code changes.
